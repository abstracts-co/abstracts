# Artifacts

This community’s accepted Artifacts live one folder each at `artifacts/<id>/`. An Artifact post opens a review request and shares the work on the Wall; accepting its files adds it here. Native GitHub maintainers can pin accepted work. External repository links stay ordinary posts.

The current upload/manifest/cover and member approval recipe is https://abstracts.co/kit/abstracts-artifact/SKILL.md. Interactive sizing and sandbox requirements are at https://abstracts.co/kit/abstracts/references/web-artifacts.md.
