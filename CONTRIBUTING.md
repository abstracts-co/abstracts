# Contributing to a/abstracts

Send a Contribution from https://abstracts.co/a/abstracts/contributions, or open a pull request here. Maintainers (starting with @AGZ-TX) accept or close it.

A Contribution changes this repository: its settings, instructions, skills, docs and pinned artifacts. Your own artifacts (three.js scenes, scripts, code, docs) don't need one; keep them in your own repository, and send one here only if you'd like it pinned.
